# 儿童自律计划程序开发设计方案

## 1. 项目目标

这个项目要做的是一个给孩子使用的电脑端自主管理程序。它不是普通的番茄钟，也不是家长后台式任务系统，而是一个类似实体儿童计划板的交互工具：

- 孩子可以自己选择今天要做的事情。
- 孩子可以自己调整任务顺序。
- 孩子可以自己旋转计时器选择专注时长。
- 计时器和右侧计划不是强绑定关系。
- 孩子完成后自己点击完成或未完成。
- 家长负责提前准备任务模板和奖励规则。

第一版先在电脑上运行，后续再考虑 App、PWA、硬件屏幕或 AI 计划生成。

## 2. 核心设计原则

### 2.1 不依赖键盘输入

孩子年龄较小，不适合频繁打字。儿童端所有关键操作优先使用：

- 点击
- 拖拽
- 上下移动按钮
- 图标选择
- 颜色选择
- 旋钮式时间选择

文字录入主要放在家长端。

### 2.2 计时器独立于计划

左侧计时器是自由工具，不由右侧任务固定控制。孩子可以：

- 单独设置 5、10、15、20、30、45、60 分钟。
- 点击某个计划后自动带入建议时间。
- 手动调整建议时间。
- 计时结束后再决定是否完成某个计划。

所以系统中应当允许 `timer_sessions` 不绑定任何任务。

### 2.3 孩子拥有选择感

家长不是每天替孩子安排所有细节，而是维护任务模板库。孩子从模板库中选择今日计划，就像搭积木一样排列。

这可以让孩子感到“这是我的计划”，不是“别人塞给我的任务”。

### 2.4 奖励要及时、明确、轻量游戏化

完成任务后立刻反馈：

- 星星增加
- 金币增加
- 简短鼓励语
- 音效
- 小动画
- 贴纸或徽章

第一版先做星星和鼓励语，动画和贴纸后续再加。

### 2.5 控制退出，但不承诺系统级锁死

Python 桌面程序可以实现：

- 全屏显示
- 窗口置顶
- 关闭时要求家长密码
- 程序内退出需要家长密码

但是不能承诺百分百阻止任务管理器、强制关机、切换账户等系统级行为。后续如果需要强控制，应配合 Windows 儿童账户、家长控制或 kiosk 模式。

## 3. 用户角色

### 3.1 孩子

孩子端只需要做几件事：

1. 从任务模板中选今天要做什么。
2. 调整今天计划的顺序。
3. 旋转计时器选择专注时间。
4. 点击开始、暂停、重置。
5. 对计划点击完成或未完成。
6. 查看星星、金币和完成进度。

### 3.2 家长

家长端负责维护规则：

1. 设置家长密码。
2. 创建任务模板。
3. 修改任务名称、图标、分类、建议时间、奖励星星。
4. 查看孩子每日完成记录。
5. 设置奖励规则。
6. 退出全屏或关闭程序。

## 4. 第一版 MVP

第一版只做能闭环的核心功能：

```text
启动程序
进入儿童全屏主页
孩子从模板库选择今日计划
孩子调整计划顺序
孩子旋转计时器选择时长
孩子开始倒计时
倒计时结束后提醒
孩子手动点击完成
系统发放星星
家长输入密码才能退出
```

第一版暂不做：

- AI 自动生成计划
- 多设备同步
- 云账号
- 复杂宠物养成
- 系统级应用拦截
- 手机 App

## 5. 页面设计

### 5.1 儿童主界面

布局参考实体儿童计划板：

```text
┌──────────────────────────────────────────────┐
│ 顶部：今天日期 / 星星数量 / 家长入口           │
├───────────────────────┬──────────────────────┤
│ 左侧：自由计时器       │ 右侧：今日计划         │
│                       │                      │
│ 圆形旋钮              │ 任务卡片 1     完成按钮 │
│ 大号倒计时            │ 任务卡片 2     完成按钮 │
│ 开始/暂停/重置         │ 任务卡片 3     完成按钮 │
│                       │                      │
│ 常用时间快捷按钮       │ 添加计划 / 排序         │
└───────────────────────┴──────────────────────┘
```

### 5.2 计划选择界面

孩子从家长准备好的模板中选择任务：

```text
点击“选择任务”按钮后弹窗：

任务模板库
阅读20分钟       加入
练字30分钟       加入
整理书包         加入
跳绳30下         加入
```

交互方式：

- 点击“加入”加入今日计划。
- 点击上移/下移调整顺序。
- 点击删除移除今日计划。
- 不要求孩子输入文字。

### 5.3 计时器界面

计时器不绑定任务，但可以从任务建议时间快速带入。

功能：

- 旋钮选择分钟数。
- 快捷选择常用时间。
- 开始、暂停、继续、重置。
- 倒计时结束播放提示音。
- 结束后展示“你可以去右侧勾选完成啦”。

### 5.4 家长登录

入口使用小锁图标。点击后弹窗输入密码。

第一版默认密码可以是 `1234`，首次进入后提醒家长修改。

### 5.5 家长设置

家长设置包含：

- 任务模板管理
- 奖励规则
- 完成记录
- 程序设置
- 退出程序

第一版重点先做任务模板管理和退出程序。

## 6. 数据模型

### 6.1 task_templates

家长维护的任务模板库。

```text
id                主键
title             任务名称
icon              图标名称
category          分类：study/life/sport/rest/custom
suggested_minutes 建议分钟数
reward_stars      完成奖励星星
sort_order         排序
is_active          是否启用
created_at         创建时间
updated_at         更新时间
```

### 6.2 daily_plan_items

孩子每天选择出来的计划。

```text
id             主键
plan_date      日期
template_id    来源任务模板
sort_order     当日排序
status         pending/completed/failed/skipped
completed_at   完成时间
created_at     创建时间
```

### 6.3 timer_sessions

计时器使用记录。

```text
id                  主键
selected_minutes    孩子选择的分钟数
actual_seconds      实际运行秒数
started_at          开始时间
ended_at            结束时间
status              running/completed/cancelled
linked_plan_item_id 可选，关联某个今日计划
```

### 6.4 reward_logs

奖励记录。

```text
id            主键
plan_item_id  可选，关联完成的计划
stars         星星数量
reason        奖励原因
created_at    创建时间
```

### 6.5 settings

程序设置。

```text
key    设置名
value  设置值
```

常见设置：

```text
parent_password_hash
start_fullscreen
always_on_top
total_stars
```

## 8. 技术路线

### 8.1 桌面 UI

使用 PySide6。理由：

- 能做全屏桌面应用。
- 能实现自定义圆形旋钮。
- UI 表现力比 Tkinter 更好。
- 后续可以打包成 exe。

### 8.2 本地数据库

使用 SQLite。理由：

- 不需要安装数据库服务。
- 单机程序足够。
- 方便备份。
- Python 标准库直接支持。

### 8.3 打包

后续使用 PyInstaller：

```powershell
pyinstaller --noconfirm --windowed --name ChildPlanner main.py
```

第一阶段不急着打包，先保证功能好用。

## 10. 关键交互规则

### 10.1 点击计划卡片

- 将计时器切换到该任务的建议时间。
- 不自动开始计时。
- 不自动完成任务。

### 10.2 计时结束

- 播放提示。
- 显示鼓励语。
- 提醒孩子去右侧选择完成状态。
- 不自动把任务标记为完成。

### 10.3 点击完成

- 当前计划状态变为 completed。
- 发放任务模板中配置的星星。
- 写入 reward_logs。

### 10.4 点击未完成

- 当前计划状态变为 failed。
- 不发放星星。
- 给温和提示，避免羞辱式反馈。

### 10.5 退出程序

- 必须通过家长密码。
- 关闭窗口事件也应拦截并弹出密码框。

## 12. 风险和边界

### 12.1 不做过强惩罚

儿童自律产品应该强调正向反馈，不做恐吓、羞辱、扣分过重等设计。

### 12.2 不承诺系统级防逃逸

全屏和密码退出只是应用级控制。真正系统级限制需要 Windows 设置配合。

### 12.3 避免功能过早复杂

先把孩子愿意使用的闭环做好，再做 AI、云同步、宠物养成。
